# CCS SharePoint

Build packs for the Colleague & Customer Service (CCS) SharePoint estate.

| Folder | What it is | Start with |
|---|---|---|
| `ccs-sharepoint-build-pack/` | The whole estate: CCS hub, four Lab hubs, Frontier, team business and private sites. Guides, page build sheets, assets, themes, lists, Power BI and Deneb, provisioning scripts, the CCS agent | `README.md`, then `design/offline/index.html` |
| `ccs-frontier-build-pack/` | Frontier on its own, with placeholder images for the Power BI visuals | `index.html` |

Names, figures and quotes in the designs and sample data are illustrative. The live designs are on the Claude canvas.
