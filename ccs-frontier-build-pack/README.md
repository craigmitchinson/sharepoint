# Frontier build pack

Open `index.html` in Edge or Chrome. It is the front page for everything here: the seven Frontier pages (clickable), the brand, the icons, the Power BI visuals with their placeholders, the lists and the folder structures.

Then build from `01-frontier-build-guide.md` and `02-page-build-sheets.md`.

Files whose names start with `PLACEHOLDER_` stand in for Power BI visuals until the Frontier report is published. Names, figures and quotes on the pages are sample content.
