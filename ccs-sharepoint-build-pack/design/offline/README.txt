CCS SharePoint mock-up, offline copy

Unzip the whole folder, keep the folders together, and open index.html in Edge or Chrome.
Every page links to the others as it would in SharePoint. The Page map button returns to the index;
the Web part labels button shows which SharePoint web part builds each block.
Nothing is sent anywhere: there are no external calls, fonts or scripts.
Figures, names and quotes are illustrative mock data.
