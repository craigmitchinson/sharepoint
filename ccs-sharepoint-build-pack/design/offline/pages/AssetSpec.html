The front door model

Four intents replace the six robot-specific routes, for every solution type. One Requests list holds all four as content types, linked to the Solutions catalogue. Urgent live incidents go to ServiceNow, never the list.

IntentReplacesContent type fieldsRoutes to
Ask a questionAsk a question about a robotSolution, DetailsService Team lead
Report a problemRaise a bugSolution, What happened, Impact, StartedService Team (urgent: ServiceNow incident)
Change somethingRaise a change request, Schedule change, Impact assessmentSolution, Change type (what it does / when it runs / a system it uses is changing), DetailsService Team; impact assessments to the Lead Solution Architect
Bring us something newRaise a new opportunityBusiness area, Monthly volume, Minutes per case, What hurtsProduct Owner (Qualified gate)
